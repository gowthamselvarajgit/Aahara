# Agent Skills

This repository currently relies on the built‑in Antigravity skills for general development assistance. No custom skills have been added yet.

## Available Built‑in Skills
- **agy‑customizations** – guides on customizing the agent, loading order, and creating skills/rules.
- **antigravity‑guide** – overview of Antigravity CLI, IDE, and SDK usage.
- **ui‑ux‑pro‑max** – UI/UX design resources.

### Future Skill Additions
- **React Native Helper** – scripts for generating components, navigation scaffolding.
- **Spring Boot Helper** – shortcuts for creating controllers, services, and JPA entities.
- **Data Pipeline Helper** – utilities for ingesting nutrition datasets.

When needed, custom skills can be added under `.agents/skills/<skill-name>/SKILL.md` and will be discovered automatically.
